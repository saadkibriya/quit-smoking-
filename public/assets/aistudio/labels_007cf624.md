# labels.md — Exact Words to Use

Rule: every button/title in the app must use these words. No jargon.

| Where | Old | New | Why |
|---|---|---|---|
| Home main button | SOS | **Ride out a craving** | Says exactly what you get |
| Its subtitle | — | 3-minute breathing to get through the urge | Sets expectation |
| Widget button | SOS | **Craving help** | Short enough for a widget |
| 1×1 widget label | — | **Craving** | Fits 1×1 |
| Log button | Reset / Relapse / (whatever exists) | **I smoked** | Plain, honest, no blame |
| Its subtitle | — | Logs it and restarts your timer | Explains the result |
| After logging | — | Logged. Your timer restarted. You still have [X] smoke-free days behind you. | Prevents all-or-nothing thinking |
| Undo | — | **Undo** | Standard |
| History item | Relapse | **Slip** | Non-shaming |
| Edit tiles | (icon / "Edit") | **Customize home** | Clear purpose |
| Add tile | (+ / "Add tile") | **Add a card** | Plain language |
| Edit sections | — | **On your home** / **Add a card** | Clear |
| Reset layout | — | **Reset to simple layout** | Clear |
| Craving end question | — | Did the urge pass? | Simple |
| Craving answers | — | Yes, it passed · Still strong · I smoked | Simple choices |
| Craving extras | — | Distract me · My reasons · Change breathing | Explicit |
| Craving hint | — | Cravings usually pass in 3–5 minutes. | Reassures |
| Success | — | That's [N] cravings beaten | Positive |
| Stats screen | Dashboard / Stats | **Progress** | Friendlier |
| Widget timer label | — | SMOKE-FREE | Short |
| Widget empty state | — | Set your quit date | Clear next step |
| Battery help (Settings) | — | Widget not updating? Fix it here | Practical |
| Accessibility: log | — | Log a cigarette | Screen readers |
| Accessibility: craving | — | Open craving help | Screen readers |

Never use: "You failed", "Start over", "Relapse", "SOS".
